# 🚀 Landing Page com Automação de Leads

Landing page responsiva desenvolvida para captação e gestão automática de leads, integrada com serviços de automação em nuvem.

## 🛠️ Tecnologias Utilizadas
- **Front-End:** HTML5, CSS3, JavaScript (Fetch API, manipulação do DOM, gestão de estados assíncronos).
- **Automação & Back-End:** Make.com (Custom Webhooks).
- **Base de Dados:** Google Sheets.
- **Comunicação:** Gmail (envio automático de e-mail de confirmação).

## ⚙️ Funcionalidades
- Validação de campos e feedback visual dinâmico (sucesso/erro).
- Gestão de estado do botão de envio (*loading*) para evitar cliques duplos.
- Comunicação assíncrona via requisição `POST` com payload JSON.
- Armazenamento automático do lead numa folha do Google Sheets em tempo real.
- Disparo automático de e-mail personalizado de resposta para o cliente.
